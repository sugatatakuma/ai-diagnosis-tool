# AI業務改善インパクト診断

12問でAIによる業務改善余地を可視化する診断ツール。

## 概要

中小企業の経営者・管理職向けに、現在の業務の課題（属人化・繰り返し作業・書類業務・問合せ対応など）とAI活用準備度を診断し、改善余地を月間削減時間レンジ・年間コスト換算で提示します。

- **質問数**: 12問（所要約3分）
- **出力**: 4タイプ判定（A/B/C/D）+ 課題スコア + 準備度スコア + 削減時間レンジ
- **送信内容**: メールアドレスを起点に詳細レポートを送付（任意項目：名前・会社名）

## 構成

| 要素 | 用途 |
|------|------|
| GitHub Pages | 静的ホスティング |
| Cloudflare Turnstile | Bot対策（CAPTCHA代替） |
| Make Webhook | サーバー側スコア再計算・データ保存・メール送信 |
| Google Sheets | リード情報蓄積 |
| Gmail / SendGrid | 結果メール配信 |
| GA4 | アクセス計測 |
